# Script hỗ trợ

Nơi đặt script setup môi trường, seed dữ liệu demo và tác vụ dự án khi có nhu cầu thực tế.

Mỗi script cần mô tả cách chạy, tham số, môi trường tác động và điều kiện tiên quyết. Seed dùng dữ liệu giả; không đưa secret, bằng chứng hoặc thông tin người dùng thật vào Git. Các script thay đổi dữ liệu cần kiểm tra đúng môi trường trước khi chạy.

Hiện chưa có script thực thi.
