# Roadmap 21 ngày

Các mốc tính từ ngày nhóm bắt đầu; chưa gắn với ngày lịch cụ thể. Đây là kế hoạch trong tài liệu phân tích, không phải báo cáo công việc đã hoàn thành.

| Mốc | Công việc chính | Kết quả nghiệm thu |
| --- | --- | --- |
| Ngày 1–3 | Chốt actors, workflow, business rules, ERD, API contract; setup repo | SRS rút gọn + ERD + Swagger skeleton |
| Ngày 4–7 | Auth, Post CRUD, DB migration; UI tạo/xem tin | Đăng nhập và đăng tin chạy end-to-end |
| Ngày 8–10 | Search, matching quy tắc, claim; API tests | Có gợi ý và gửi claim được |
| Ngày 11–14 | Verification, return workflow, tích hợp UI, regression | MVP từ đăng tin đến xác nhận trao trả |
| Ngày 15–17 | Notification, admin, bảo mật, edge cases | Luồng ổn định, không còn lỗi nghiêm trọng |
| Ngày 18–19 | Feature freeze, Docker/deploy, tài liệu, seed demo | Bản triển khai + README + test report |
| Ngày 20–21 | Tổng duyệt, Sprint Demo, Sprint Review | Demo hoàn chỉnh + báo cáo phân công |

Bộ khung hiện tại chỉ hỗ trợ phần setup repo/tài liệu ban đầu của ngày 1–3. ERD, API contract và Swagger skeleton vẫn cần triển khai. Theo dõi task thực tế bằng GitHub Projects nếu nhóm sử dụng công cụ này.
