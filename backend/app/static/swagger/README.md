Swagger UI **5.35.0**, from the official `swagger-ui-dist@5.35.0` npm package.
Only the browser bundle, stylesheet, favicon and upstream LICENSE are vendored.
Source: https://github.com/swagger-api/swagger-ui/tree/v5.35.0

Served locally so `/docs` supports OpenAPI 3.1 without a CDN connection.
The older Python `swagger-ui-bundle` package ships UI 4.15.5 and is unsuitable
for the generated OpenAPI 3.1 schema.
